## About

This repo holds my LeetCode solutions, organized by topic and difficulty. I solve problems regularly to stay sharp on data structures and algorithms while working as an AI/ML engineer.

## Problem-Solving Approach

1. **Understand** — read the problem carefully, note constraints
2. **Examples** — trace through the given examples by hand
3. **Brute Force** — start with the naive solution
4. **Optimize** — find the bottleneck, apply the right pattern
5. **Code** — write clean, readable code with edge cases handled
6. **Complexity** — note time and space complexity
